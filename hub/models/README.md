# Edge models

Default: `tiny_edge.onnx` (generated by `gen_tiny_edge.py`) — CPU ONNX Runtime,
four logits `{safe, edge, obstacle, unknown}`, biased to `unknown`.

To use a real NVIDIA TAO export (DetectNet_v2 ResNet10 or MobileNet-V2, ONNX INT8, ≤15 MB):

```
cp detectnet.onnx hub/models/
```

The model may only vote `stop` / `back_off`. IR cliffs on the robot still win.
